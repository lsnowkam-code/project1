# 📅 Динамические годы в системе

## Проблема (была)
Система была "завязана" на годы 2022-2023. При переходе на 2024-2025 требовалось переписывать код.

## Решение (сейчас)
Система теперь **полностью динамична**. Годы берутся автоматически из Word документа и преобразуются следующим образом:

---

## 🔄 Поток преобразования годов

### Этап 1: Извлечение из Word (logic.py)
```
Word таблица: столбец с заголовком "2024"
                ↓
Функция: _extract_year("2024") → "2024"
                ↓
Функция: _extract_year_suffix("2024") → "24"
                ↓
Результат: тег {{OKVED_01_ValBal_24}}
```

### Этап 2: Заполнение данных (data_filler_v2.py)
```
Тег с суффиксом: {{OKVED_01_ValBal_24}}
                ↓
Парсинг: last_part="24" (2 цифры) → это суффикс года
                ↓
Поиск в master_data по ключу "ValBal_24"
                ↓
Если не найдено → fallback на альтернативный год
```

### Этап 3: Ключевые слова для поиска (config_v2.py)
```
Excel структура: "Валюта баланса | на конец 2024"
                ↓
Функция: _extract_keywords_for_year(..., year="24")
                ↓
Результат: "2024", "конец", "Валюта баланса"
                ↓
Эти слова используются для "умного" поиска колонки
```

---

## 🔧 Как это работает для любого года

| Год | Суффикс | Логика |
|-----|---------|---------|
| 2022 | 22 | Последние 2 цифры года |
| 2023 | 23 | Последние 2 цифры года |
| 2024 | 24 | Последние 2 цифры года |
| 2025 | 25 | Последние 2 цифры года |
| **2099** | **99** | Последние 2 цифры года |

**Правило:** Суффикс = последние 2 цифры года. Просто и универсально! ✨

## 📝 Обновленные функции

### logic.py
- **`_extract_year_suffix(year_text: str)`** — преобразует "2024" → "24"
  - Используется везде в logic.py для консистентного преобразования
  - Работает для любого 4-значного года

### data_filler_v2.py
- **`_map_year_to_suffix(year: str)`** — преобразует "2024" → "24"
  - Используется для обработки годов при заполнении тегов
  - Заменила жесткую логику (< 2023 → '22', >= 2023 → '23')

### config_v2.py
- **`_extract_keywords_for_year(..., year: str)`** — генерирует ключевые слова
  - Теперь работает универсально для любых годов
  - Добавляет маркеры периода ("начало", "конец") на основе суффикса, а не года
  - Не зависит от конкретных лет

## ✅ Что нужно сделать при переходе на 2025+

### В Word документе
- Просто обновите заголовки таблиц с новым годом: "2024" → "2025"

### В Excel файлах
- Если года изменились, обновите столбцы с новыми данными

### В коде
- **НИЧЕГО НЕ МЕНЯТЬ!** 🎉
- Система автоматически:
  - Извлечет год из Word (2025)
  - Преобразует в суффикс (25)
  - Найдет данные по правильному ключу
  - Заполнит теги

## 🔍 Где искать логику

- **Извлечение годов:** `logic.py`, функция `_find_year_header_row()`, `_extract_year()`
- **Преобразование в суффиксы:** `logic.py`, функция `_extract_year_suffix()` + `data_filler_v2.py`, функция `_map_year_to_suffix()`
- **Парсинг тегов:** `data_filler_v2.py`, функция `fill_word_template_by_tags_v2()`, строки ~295-320
- **Генерация ключевых слов:** `config_v2.py`, функция `_extract_keywords_for_year()`

---

## ⚠️ Важные замечания

1. **Всё нужно обновить синхронно:** Если в Word новый год — обновите Excel данные на соответствующие годы
2. **Суффиксы должны совпадать:** Если Word говорит "2024", то в Excel данные должны быть в колонке для года 2024
3. **Fallback работает:** Если данные не найдены по суффиксу "24", система попробует найти по "22" или "23"
