Переход от жестких привязок к индексам на семантический поиск, что позволит:
- ✅ Находить данные несмотря на изменения названий таблиц

- ✅ Автоматически нормализовать данные перед вставкой
- ✅ Получать результат идентичный эталону

## 🔧 ЭТАП 2: Алгоритмы умного поиска (ГОТОВО ✅)

### 📚 Созданные модули:

#### `smart_loader.py` - Умный поиск данных
Функции:
- **`normalize_text(text)`** — нормализует текст для сравнения
  - Убирает пробелы, скобки, приводит к нижнему регистру
  - Пример: "Активы (тыс.руб)" → "активы"

- **`fuzzy_match(target, candidates, threshold)`** — нечеткое совпадение
  - Ищет лучшее совпадение в списке кандидатов
  - Пример: "Внеоборотные активы" найдет "Внеоборотные активы (тыс.руб)" с сходством 95%

- **`find_column_by_year(df, year, year_markers)`** — динамический поиск колонки
  - Ищет колонку по году ("2023") или маркерам периода ("На конец")
  - Вместо жесткого индекса 4
  - Работает, даже если столбцы переставлены

- **`find_row_by_fuzzy_match(df, target_name, threshold)`** — нечеткий поиск строк
  - Находит строку по названию показателя с нечетким совпадением
  - Устойчива к опечаткам и вариациям текста

#### `data_normalizer.py` - Очистка и нормализация данных
Функции:
- **`normalize_number_string(value)`** — очистка чисел
  - "569 800 589" → "569800589"
  - "- " → "-"
  - "1 234,56" → "1234,56"

- **`clean_excel_value_for_word(value)`** — комплексная очистка
  - Применяет все необходимые нормализации
  - Готовит значение к вставке в Word

- **`compare_with_template(original, normalized)`** — для отладки
  - Показывает что изменилось при нормализации

### 📁 Файлы:
- `/smart_loader.py` — модуль поиска
- `/data_normalizer.py` — модуль нормализации

## ⚙️ ЭТАП 3: Обновленная логика загрузки (ГОТОВО ✅)

### 📚 Новые модули:

#### `config_v2.py` - Расширенная конфигурация
- **`load_column_mapping_v2(filepath)`** — загружает маппинги с ключевыми словами
  - Читает column_mapping_v2.csv
  - Парсит ключевые слова из кавычек
  - Возвращает `indicator_keywords` для каждого показателя

#### `data_filler_v2.py` - Новый заполнитель с умным поиском
- **`pre_load_all_excel_data_v2(...)`** — загружает данные с умным поиском
  - Использует `find_column_by_year` вместо жестких индексов
  - Автоматически нормализует данные через `clean_excel_value_for_word`
  - Логирует все действия (найдено по ключевым словам, по индексам, ошибки)
  - Возвращает `(master_data, stats)` с подробной статистикой

- **`_find_column_smart(df, hardcode_idx, year, keywords)`** — иерархический поиск
  1. Пытается найти по ключевым словам
  2. Пытается найти по году
  3. Fallback на жесткий индекс (для совместимости)

- **`fill_word_template_by_tags_v2(...)`** — заполнение с нормализацией
  - Парсит теги вида `{{OKVED_code_indicator_year}}`
  - Применяет финальную нормализацию перед вставкой
  - Логирует каждое заполнение

### 📁 Файлы:
- `/config_v2.py` — расширенная конфигурация
- `/data_filler_v2.py` — новый заполнитель
