# Правила для динамического маппинга таблиц в Excel и Word

## 🎯 Цель
Заменить фиксированный маппинг `column_mapping.csv` на динамическую систему, которая автоматически выявляет:
1. Какой файл содержит какие показатели
2. Какие колонки содержат данные за 2022 и 2023
3. Названия показателей на основе содержимого

---

## 📋 УРОВЕНЬ 1: Идентификация источника (Excel файл)

### Правило L1.1: По названию файла
```
Паттерн: T23_000000_tXXVed14.xlsx
Извлечение: XX определяет тип данных

t01 → Баланс организаций
t03 → Внеоборотные активы
t10 → Оборотные активы
t13 → Оборачиваемость оборотных активов
t19 → Капитал и резервы
t20 → Долгосрочные обязательства
t21 → Краткосрочные обязательства
```

### Правило L1.2: Валидация по первой строке (Row 0)
```
Сигнатура в Row[0][col]: "XXX XXXX за 2023 год"

Примеры:
- "Баланс организаций за 2023 год" → t01
- "Внеоборотные активы за 2023 год" → t03
- "Оборотные активы за 2023 год" → t10
- "Капитал и резервы за 2023 год" → t19
- "Долгосрочные обязательства за 2023 год" → t20
- "Краткосрочные обязательства за 2023 год" → t21
```

---

## 📍 УРОВЕНЬ 2: Локализация показателей (Колонки)

### Правило L2.1: Структурированный поиск заголовков
```
Позиция 0: Row[4] - ГЛАВНЫЕ показатели (основные группы)
Позиция 1: Row[5] - ПОД-показатели (детализация)
Позиция 2: Row[6] - Периоды ("на конец предыдущего года", "на конец отчетного года")
```

### Правило L2.2: Навигация через Row[4] (основные заголовки)
```
Структура Row[4]:
[0]: "Код" → первая колонка с ОКВЭД кодами
[1]: "Наименование" → вторая колонка с названиями
[2+]: Названия показателей (может быть 1-8+ показателей)
```

### Правило L2.3: Обнаружение вложенных показателей (Row[5])
```
Если Row[4][col] содержит общее название (например, "Внеоборотные активы"),
то Row[5][col] содержит детальный показатель:

Row[4]: "Внеоборотные активы"
         ↓
Row[5]: "нематериальные активы", "основные средства", "долгосрочные финансовые вложения"
```

### Правило L2.4: Обнаружение периодов (Row[6])
```
Типичные значения:
- "на конец предыдущего года" → год 2022
- "на конец отчетного года" → год 2023
- "2022", "2023" → простой формат

Алгоритм:
1. Прочитать Row[6]
2. Если содержит "предыдущего" → 2022
3. Если содержит "отчетного" → 2023
```

## 🔍 УРОВЕНЬ 3: Маппинг показателей (Семантический)

### Правило L3.1: Нормализация названий показателей
```
Функция: normalize(text)
1. Приводить к нижнему регистру
2. Удалять диакритические знаки (ё→е)
3. Сокращать кратные пробелы
4. Удалять скобки и пояснения

Примеры:
"Валюта баланса" → "валюта баланса"
"краткосрочные финансовые вложения (за исключением денежных эквивалентов)" 
  → "краткосрочные финансовые вложения"
```

### Правило L3.2: Семантическое сопоставление с кодами (Справочник)
```
"валюта баланса"                        → ValBal
"внеоборотные активы"                   → VneObAk
"оборотные активы"                      → ObAk / ObAkObr
"нематериальные активы"                 → NemAk
"основные средства"                     → OsnSr
"долгосрочные финансовые вложения"      → DolgFinVl
"краткосрочные финансовые вложения"     → FinVlKr
"денежные средства"                     → DenSr
"дебиторская задолженность"             → DebZad
"кредиторская задолженность"            → KredZad
"капитал и резервы"                     → KapRez
"уставный капитал"                      → UstKap
"долгосрочные обязательства"             → DlOb
"краткосрочные обязательства"            → KrOb

Алгоритм подбора:
1. Найти максимальное совпадение (longest match)
2. Если совпадение > 70% → принять
3. Если нет → использовать fuzzy matching
```

### Правило L3.3: Fuzzy matching для неточных совпадений
```
Использовать похожесть строк (Levenshtein distance):

"краткосрочные финансовые вложения за исключением денежных эквивалентов"
  ≈ "краткосрочные финансовые вложения"
  Score: 0.85 → принять как FinVlKr

Пороги:
- > 0.85: принять без сомнений
- 0.75-0.85: требует контекста
- < 0.75: отклонить
```

## 🎯 УРОВЕНЬ 4: Полный алгоритм экстракции

### Алгоритм `extract_mapping_from_excel(filepath)`

```
Вход: Excel файл
Выход: Маппинг показателей

Шаги:
1. extract_file_type(filepath) → Тип файла (t01, t03, и т.д.)
2. validate_from_row_0(row_0) → Подтверждение типа
3. parse_row_4_headers(row_4) → Получить основные показатели
4. parse_row_5_subheaders(row_5, row_4) → Получить детализацию
5. parse_row_6_periods(row_6) → Определить колонки (2022 vs 2023)
6. normalize_and_match(headers) → Привести к кодам показателей
7. get_sample_data_from_row_8() → Валидировать наличие данных
8. confidence_scoring() → Оценить уверенность

Возврат: {
    ("T23_000000_t03Ved14.xlsx", "долгосрочные финансовые вложения"): {
        "indicator": "DolgFinVl",
        "year_2022": 17,
        "year_2023": 18,
        "confidence": 0.95
    }
}
```

## 💡 Применение для Word документов

### Синхронизация Word таблиц с Excel

```
Word Table "Внеоборотные активы" 
  → Ищем в каких Excel это содержится
  → Находим T23_000000_t03Ved14.xlsx
  → Применяем соответствующий маппинг
```

**Алгоритм `find_excel_source_for_word_table(word_table)`:**

```
1. Прочитать заголовок Word таблицы (первые 5 строк)
2. Нормализовать текст
3. Для каждого известного Excel:
   - Получить сигнатуру из Row[0]
   - Вычислить similarity к Word таблице
4. Найти Excel с максимальным similarity (> 0.7)
5. Вернуть соответствующий маппинг
```

## ✅ Практический пример для DolgFinVl

**Как система должна работать:**

```
1. Считать Excel файл T23_000000_t03Ved14.xlsx
↓
2. Row[0] = "Внеоборотные активы за 2023 год" 
   → Тип t03: Внеоборотные активы ✓
↓
3. Row[4] = ["Код", "Наименование", "Внеоборотные активы", ...]
   Row[5] = ["", "", "нематериальные активы", "основные средства", "долгосрочные финансовые вложения", ...]
   → Проверяем совпадения
↓
4. Row[5][col=4] = "долгосрочные финансовые вложения"
   Нормализация → "долгосрочные финансовые вложения"
   Сопоставление → код DolgFinVl
↓
5. Row[6][col=4] = "на конец предыдущего года" → Колонка 2022
   Row[6][col=5] = "на конец отчетного года" → Колонка 2023
↓
6. Результат: DolgFinVl размещено в колонках 17-18
   Уверенность: 1.0 (полном совпадение)
```

## 🔧 Рекомендации по реализации

### Библиотеки:
- `rapidfuzz` для fuzzy matching (Levenshtein)
- `pymorphy2` для морфологии русского языка

### Этапы внедрения:
1. **Фаза 1:** Реализовать L1 (Identification)
2. **Фаза 2:** Реализовать L2 (Localization)
3. **Фаза 3:** Реализовать L3 (Semantic matching)
4. **Фаза 4:** Заменить load_column_mapping_v2 на extract_mapping_from_excel

### Преимущества:
✓ Нет зависимости от manual CSV
✓ Автоматически адаптируется
✓ Transparent confidence scores
✓ Можно расширять без переписания кода

## 📊 Матрица достоверности

```
Confidence Level:

1.0  | Точное совпадение + Валидировано
0.95 | Fuzzy match > 0.9 + Валидировано
0.85 | Fuzzy match 0.8-0.9 + Валидировано
0.75 | Fuzzy match 0.75-0.8 + Требует проверки
0.0  | Не найдено

Действие:
> 0.9   : Использовать автоматически
0.75-0.9: Логировать, использовать с warning
< 0.75  : Требует ручного подтверждения
```
