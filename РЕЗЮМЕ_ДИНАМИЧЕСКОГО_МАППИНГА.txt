❓ ВОПРОС:
"Если бы мы писали правило для динамического маппинга (сейчас у нас 
фиксированный маппинг column_mapping.csv) по которому можно выявить 
заголовок таблиц в excel и word то какое оно было бы?"

✅ ОТВЕТ:
Это правило строится на 5 уровнях с использованием структурированного анализа
и семантического сопоставления.


═══════════════════════════════════════════════════════════════════════════════
                        ОСНОВНОЕ ПРАВИЛО
═══════════════════════════════════════════════════════════════════════════════

    INPUT: Excel файл или Word таблица
       │
       ├─► УРОВЕНЬ 1: Идентификация (Какой тип источника?)
       │         Алгоритм: Parce имя файла (t01-t21) + Read Row[0]
       │         Результат: File Type (например, t03 = Внеоборотные активы)
       │         Confidence: 1.0 (если совпадает)
       │
       ├─► УРОВЕНЬ 2: Локализация (Где находятся показатели?)
       │         Алгоритм: Row[4] → основные заголовки
       │                   Row[5] → подпоказатели (детализация)
       │                   Row[6] → периоды (2022 vs 2023)
       │         Результат: {Колонка → (Показатель, Год)}
       │
       ├─► УРОВЕНЬ 3: Семантика (Текст → Код показателя)
       │         Алгоритм: Normalize → Dictionary Match → Fuzzy Match
       │         Результат: Код показателя (DolgFinVl, ObAk и т.д.)
       │         Confidence: 0.75-1.0 (зависит от метода)
       │
       ├─► УРОВЕНЬ 4: Структурирование (Построить маппинг)
       │         Алгоритм: {(Файл, Показатель_norm) → (Код, Col22, Col23)}
       │         Результат: Готовый маппинг с уровнями доверия
       │
       └─► УРОВЕНЬ 5: Использование (Применить маппинг)
           Алгоритм: Найти данные в Excel → Заполнить Word таблицы
           Результат: Заполненные теги {{OKVED_XX_Indicator_YY}}


═══════════════════════════════════════════════════════════════════════════════
                    КЛЮЧЕВЫЕ КОМПОНЕНТЫ ПРАВИЛА
═══════════════════════════════════════════════════════════════════════════════

1️⃣  ПАТТЕРНЫ ИДЕНТИФИКАЦИИ
    ───────────────────────

    Паттерн файла: T23_000000_tXXVed14.xlsx
    ├─ t01 → "Баланс организаций"
    ├─ t03 → "Внеоборотные активы"  ← где находится DolgFinVl
    ├─ t10 → "Оборотные активы"
    ├─ t13 → "Оборачиваемость оборотных активов"
    ├─ t19 → "Капитал и резервы"
    ├─ t20 → "Долгосрочные обязательства"
    └─ t21 → "Краткосрочные обязательства"

    Сигнатура в Row[0]: "XXX YYYY за 2023 год"
    т.е. каждый файл начинается с заголовка, содержащего тип данных + год


2️⃣  СТРУКТУРА ЗАГОЛОВКОВ В СТРОКАХ
    ──────────────────────────────────

    Row[4]: "Код" | "Наименование" | "Внеоборотные активы" | ...
    Row[5]:  ""   |       ""       | "нематер. активы"    | "основ. средства" | "долгосроч. финн. вложения"
    Row[6]:  ""   |       ""       | "на конец пред. года" | "на конец пред. года" | "на конец отчет. года"
                                                    ↓
                                            Col 3: 2022
                                            Col 4: 2022
                                            Col 5: 2023

    Правило:
    - Row[4] = основные показатели (группы)
    - Row[5] = детальные показатели (внутри каждой группы)
    - Row[6] = периоды (какой год для какой колонки)


3️⃣  СЕМАНТИЧЕСКОЕ СОПОСТАВЛЕНИЕ
    ────────────────────────────

    "долгосрочные финансовые вложения"
         ↓ Нормализация
    "долгосрочные финансовые вложения"
         ↓ Поиск в словаре
    DolgFinVl (Confidence: 1.0)

    Трехуровневый поиск:
    a) Точное совпадение в словаре       → Confidence 1.0
    b) Частичное совпадение (longest)    → Confidence 0.8-0.9
    c) Fuzzy matching (Levenshtein > 75%)→ Confidence 0.75-0.95


4️⃣  СЛОВАРЬ ПОКАЗАТЕЛЕЙ
    ────────────────────

    "валюта баланса"                    → ValBal
    "внеоборотные активы"               → VneObAk
    "нематериальные активы"             → NemAk
    "основные средства"                 → OsnSr
    "долгосрочные финансовые вложения"  → DolgFinVl  ← Главный пример!
    "краткосрочные финансовые вложения" → FinVlKr
    "компанон средства"                 → DenSr
    "дебиторская задолженность"         → DebZad
    "остальное"                         → "остальное"

    Словарь можно расширять без изменения алгоритма!


═══════════════════════════════════════════════════════════════════════════════
                    ПРАКТИЧЕСКИЙ ПРИМЕР: DolgFinVl
═══════════════════════════════════════════════════════════════════════════════

Как система найдет "долгосрочные финансовые вложения":

1. Читаем Excel: T23_000000_t03Ved14.xlsx
   ├─ Из имени → Извлечено: t03
   └─ Из Row[0] → "Внеоборотные активы за 2023 год" ✓

2. Парсим заголовки (Row 4, 5, 6):
   ├─ Row[4]: [..., "Внеоборотные активы", ...]
   ├─ Row[5]: [..., "долгосрочные финансовые вложения", ...]
   └─ Row[6]: [..., "на конец пред. года", "на конец отчет. года"]

3. Ищем показатель "долгосрочные финансовые вложения":
   ├─ Нормализуем: "долгосрочные финансовые вложения"
   ├─ Проверяем словарь: НАЙДЕНО! ✓
   └─ Результат: DolgFinVl, Confidence: 1.0

4. Определяем колонки:
   ├─ Row[6] пер.год → Колонка 17 (2022)
   ├─ Row[6] отч.год → Колонка 18 (2023)
   └─ Результат: {17: 2022, 18: 2023}

5. Валидируем данные (Row 8+):
   ├─ Прочитали значение из Col 17 → Не пусто ✓
   └─ Confidence повышена до 0.95

6. Финальный маппинг:
   {
       ("T23_000000_t03", "долгосрочные финансовые вложения"): {
           "indicator": "DolgFinVl",
           "year_2022": 17,
           "year_2023": 18,
           "confidence": 0.95,
           "validated": True
       }
   }

                    МАТРИЦА ДОСТОВЕРНОСТИ

Score  │ Метод обнаружения           │ Действие
───────┼──────────────────────────────┼────────────────────────────
1.0    │ Точное совпадение           │ ✓ Использовать автоматически
       │ + Валидировано данными      │
───────┼──────────────────────────────┼────────────────────────────
0.95   │ Fuzzy match > 0.9            │ ✓ Использовать автоматически
       │ + Валидировано              │
───────┼──────────────────────────────┼────────────────────────────
0.85   │ Fuzzy match 0.8-0.9         │ ⚠️  Логировать, использовать
       │ + Валидировано              │    (требует контекста)
───────┼──────────────────────────────┼────────────────────────────
0.75   │ Fuzzy match 0.75-0.8        │ ⚠️  Логировать warning
       │ + Требует проверки          │    (требует ручной проверки)
───────┼──────────────────────────────┼────────────────────────────
0.0    │ Нет совпадения              │ ❌ Требует ручного подтверждения

                    ПРЕИМУЩЕСТВА ДИНАМИЧЕСКОГО МАППИНГА
═══════════════════════════════════════════════════════════════════════════════

✓ Не нужен ручной CSV файл
  └─ Система сама обнаруживает показатели из содержимого

✓ Автоматически адаптируется
  └─ Если изменится структура Excel → Система пересчитает маппинг

✓ Можно добавлять новые файлы
  └─ Не нужно обновлять column_mapping.csv

✓ Прозрачность (Confidence Scores)
  └─ Видим уровень доверия для каждого маппинга

✓ Масштабируемо
  └─ Одно правило работает для всех типов таблиц

✓ Поддерживает Word
  └─ Система найдет источник Excel для любой Word таблицы
