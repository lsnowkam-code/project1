# Новый Динамический Подход к Заполнению Word Документов

## Обзор
Вместо фиксированного маппинга теперь используется **динамический поиск данных**:
- Маппинг строится по таблицам Word документа
- Excel файлы ищутся по ключевым словам заголовков
- Данные находятся через fuzzy search по смыслу показателей

## Архитектура

### 1. Рефакторинг table_source_data_mapping.csv
Упрощенный маппинг: только связь таблиц Word с Excel файлами.

Структура:
```
table_id,word_title_keyword,excel_filename
1,Валюта баланса,T23_000000_t01Ved14.xlsx
3,Внеоборотные активы,T23_000000_t03Ved14.xlsx
...
```

### 2. Модули

#### word_parser.py
- Парсит Word шаблон
- Извлекает структуру таблиц (ID, заголовки, годы, показатели)
- Определяет, какие ячейки нужно заполнить

#### smart_excel_finder.py
- Открывает Excel файл
- Динамически ищет строку с показателем (fuzzy search)
- Находит колонку с нужным годом
- Возвращает значение

#### main_generator.py
- Основной скрипт сборки
- Цикл по таблицам Word → поиск в Excel → заполнение

## Преимущества

✅ **Гибкость**: Изменения в Excel (перестановка колонок, новые строки) не ломают систему
✅ **Прозрачность**: Логи показывают, что найдено, что нет
✅ **Точность**: Данные берутся именно под те ячейки, которые есть в Word
✅ **Масштабируемость**: Легко добавить новые таблицы/показатели

## Использование

### Подготовка
1. Установлены зависимости: `pip install rapidfuzz python-docx`
2. Рефакторинг `table_source_data_mapping.csv` выполнен
3. Word шаблон готов (с таблицами и плейсхолдерами)

### Запуск
```python
from main_generator import run_generation

run_generation(
    word_template_path="путь/к/шаблону.docx",
    word_output_path="путь/к/результату.docx",
    excel_dir="./input/excel",  # Папка с Excel файлами
    mapping_file="./input/mappings/table_source_data_mapping.csv"
)
```

### Логи
- 📊 Обработка таблицы → файл Excel
- ✅ Найдено значение для показателя
- ❌ Не найдено данных (нужно проверить порог fuzzy search или добавить синонимы)

## Настройка

### Порог Fuzzy Search
В `smart_excel_finder.py`:
```python
if match and match[1] > 75:  # Изменить порог (0-100)
```

### Синонимы Годов
В `smart_excel_finder.py`:
```python
year_keywords = {
    "2022": ["2022", "предыдущего", "2021"],
    "2023": ["2023", "отчетного", "текущего"]
}
```

### Нормализация Текста
Функции `normalize_text()` и `normalize_excel_text()` можно расширить для специфических случаев.

## Тестирование

### Без Word файла
Можно протестировать `smart_excel_finder.py` отдельно:
```python
from smart_excel_finder import find_value

value = find_value("./input/excel/T23_000000_t03Ved14.xlsx", "долгосрочные финансовые вложения", "2023")
print(value)
```

Создать минимальный Word шаблон с одной таблицей для теста.
