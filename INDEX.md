## 🔍 ДЕТАЛИ КАЖДОГО ФАЙЛА

### 1. **smart_loader.py** - Ядро умного поиска

Функции:
```python
✅ normalize_text(text: str) → str
   Входе:     "  Активы (тыс.руб)  "
   Выход:     "активы"
   
✅ fuzzy_match(target, candidates, threshold) → (match, score)
   Ищет лучшее совпадение в списке
   Пример: "Внеоборотные" найдет "Внеоборотные активы (тыс.руб)" при threshold=0.80
   
✅ find_column_by_year(df, year, markers) → (col_idx, header)
   Динамический поиск колонки по году или маркерам
   Вместо: Excel колонка 4
   Используем: Найти колонку с "2023" или "На конец"
   
✅ find_row_by_fuzzy_match(df, target, threshold) → (row_idx, name, score)
   Нечеткий поиск строк с максимальным совпадением
```

Использование:
```python
from smart_loader import fuzzy_match, find_column_by_year

# Пример 1: Нечеткое совпадение
match, score = fuzzy_match(
    "Внеоборотные активы",
    ["Внеоборотные активы (тыс.руб)", "Оборотные активы"],
    threshold=0.80
)
# match = "Внеоборотные активы (тыс.руб)", score = 0.95

# Пример 2: Поиск колонки по году
col_idx, header = find_column_by_year(
    df=my_excel_dataframe,
    year="2023",
    year_markers=["На конец", "На конец года"]
)
# col_idx = 2 (индекс колонки с "2023")
```

### 4. **data_filler_v2.py** - Новый заполнитель

Функции:
```python
✅ pre_load_all_excel_data_v2(excel_dir, table_source_mapping, okved_codes_set,
                             column_mapping_path, use_fuzzy_match=True,
                             fuzzy_threshold=0.80)
   → (master_data, stats)
   
   Загружает все данные с:
   - Динамическим поиском колонок
   - Автоматической нормализацией
   - Подробным логированием

✅ fill_word_template_by_tags_v2(doc, master_data, log_path)
   → unfilled_tags
   
   Заполняет Word:
   - Парсит теги {{OKVED_code_indicator_year}}
   - Применяет финальную нормализацию
   - Логирует каждое действие

✅ _find_column_smart(df, hardcode_idx, year, keywords) → col_idx
   Иерархический поиск:
   1. По ключевым словам
   2. По году
   3. Fallback на жесткий индекс
```

Использование:
```python
from data_filler_v2 import pre_load_all_excel_data_v2, fill_word_template_by_tags_v2

# Загрузка
master_data, stats = pre_load_all_excel_data_v2(
    excel_dir=Path("input/excel"),
    table_source_mapping=table_mapping,
    okved_codes_set={"50.13.11", "50.13.12"},
    column_mapping_path=Path("input/mappings/column_mapping_v2.csv"),
    use_fuzzy_match=True,
    fuzzy_threshold=0.80
)

# Заполнение
fill_word_template_by_tags_v2(
    doc=doc,
    master_data=master_data,
    log_path=Path("output/fill_log.txt")
)
```

### 6. **column_mapping_v2.csv** - Маппинги

Структура:
```
Excel файл;Название показателя;Код показателя;Excel колонка 2022;Excel колонка 2023;Ключевое слово 2022;Ключевое слово 2023

T23_000000_t01Ved14.xlsx;Валюта баланса;ValBal;3;4;"2022","На начало";"2023","На конец"
```

**Новые колонки:**
- `Ключевое слово 2022` - маркеры для поиска колонки 2022
- `Ключевое слово 2023` - маркеры для поиска колонки 2023

**Примеры значений:**
- `"2022"` - простой поиск по году
- `"2023","На конец"` - альтернативные маркеры
- `""` - если поле не применимо (fallback на жесткий индекс)
